## 本轮实现

- 从被忽略的 `demo/data/provider.json` 加载服务端配置；环境变量覆盖文件。仓库只提供不含密钥的配置模板。
- 默认 DeepSeek 地址、模型；保留兼容提供商接口。已配置时首次打开默认真实模式，可主动选择规则模式。
- JSON 请求设置 2048 输出 token 上限，去掉非通用的 store 参数。HTTP 错误关闭响应对象，不记录供应商错误正文，不降级为演示结果。
- 地址变化时要求新密钥，避免把旧服务密钥发送到其他地址；页面提示为 configured，不将存在密钥等同于网络已验证。
- 新增显式真实两轮验收脚本；浏览器常规测试明确选择规则模式，避免配置密钥后意外产生付费请求。
