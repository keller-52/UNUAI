# 正式版操作指南

## 打开工作区

电脑运行 `python app/launch.py`，或使用 `app/start-paper-ai.bat`、`app/start-paper-ai.sh`。运行环境为 Python 3.10+，应用不依赖额外 Python 包。页面默认英文，可切换中文。

Android 安装 APK 后直接打开 PAPER AI。iOS 按 [移动安装说明](mobile_build.md) 使用签名后的设备包或模拟器程序。每台设备保存独立工作区，不会自动同步电脑数据。

## 生成新学习包

1. 添加学生，使用匿名代号、年级和班组。
2. 在 **AI connection** 中填写提供商、协议、HTTPS 地址、模型和密钥。网页填写的密钥仅保存在当前服务会话内存，重启后需重新配置；电脑也可按 `provider.example.json` 创建本地配置文件。
3. 进入 **Generate materials**，填写主题、教学背景及来源材料、目标、题组数量、题组题量、离线天数、页数预算和材料语言。
4. 生成后检查讲解、所有题目与选项、正确答案、两级提示、解析、反馈条件、跳转目标和停止条件。需要时编辑草稿后重新校验。
5. 勾选审核确认，批准当前版本。批准后的内容冻结，可打印和扫描。

AI 失败时显示错误，不使用固定规则补出材料。缩小题量、完善背景或核对连接配置后重试。

## 导出和导入已有学习包

在打开的学习轮次中选择 **Export learning package**，保存 `PKG-….paper-ai.json`。文件包含材料与记录纸编号，不包含学生身份、作答记录、完整历史、学生访问令牌或 API 密钥。

另一台设备选择 **Import learning package**。没有学生时，先创建档案，应用随后继续导入。也可读取此前“导出本轮 JSON”产生的完整自定义主题学习包；旧固定题库包、PDF、完整工作区备份或 AI 只返回的题目片段不是学习包导入格式。

导入无需 AI 连接。导入材料作为待审核草稿进入当前学生的轮次，审核批准后可打印、扫描和回收。记录纸编号与原包一致，因此可使用对应的已打印纸张。导入不会恢复原学生作答或将原学情文字计入当前学生证据。

同一学生重复导入相同材料不会新增轮次。编号相同但内容不同、属于另一学生，或记录纸编号与其他包冲突时，应用拒绝导入，保持原数据。需要带历史迁移时使用完整备份与恢复。

## 打印与纸上学习

批准后准备 **Student booklet**、**Support booklet**、**Record sheet**，教师可另外打印 **Teacher answer guide**。全部材料在开始前备齐。

电脑预览全部页面，以 A4、100% 实际大小打印，关闭浏览器页眉页脚。可直接下载 PDF；若电脑未找到 Chrome/Edge，使用打印窗口保存 PDF。按钮无反应时使用 Ctrl+P，Mac 使用 Cmd+P。

手机使用原生打印/保存 PDF。Android 在打印服务中选择保存为 PDF 或打印机；iOS 在系统打印界面预览、展开页面后分享或存入“文件”。保留记录纸的完整四个定位标记，不缩放裁切。

学生先阅读讲解，从第 1 组开始；记录首次答案，完成整组后核对，再按纸上反馈选择下一步。首次答案、提示与重试分别记录，未分配的题组留空，不将提示后答案改写为首次答案。

## 回收与下一轮

进入 **Scan & upload**，选择对应轮次，逐页上传清晰记录纸照片。核对定位点、纸张编号和识别后的表格；识别不清时手动定位或手工录入。所有空白保留未知，实际未分配的整组由教师确认。

确认记录后进入 **Learning summary** 查看观察。更新记录形成修订，相同记录不会重复计数。需要新的 AI 总结时配置连接并选择 **Summarise latest evidence**；下一轮生成只使用当前学生、当前主题已确认的记录。

批量生成、批量打印和完整备份/恢复位于 **Batch tools & backup**。备份恢复是带学生和历史的工作区迁移；学习包导入是单独复用教学材料，两者用途不同。
