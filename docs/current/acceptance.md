# 正式版验收要求

## 判定标准

功能验收覆盖“生成或导入 → 审核 → 纸张学习 → 回收 → 总结/下一轮”。自动工程测试、实物纸张检查、真实 AI 调用和真人可用性分别记录，不能相互代替。

| 项目 | 必须满足 |
| --- | --- |
| 正式界面 | 无题库预留、示例学生、规则生成或扫描测试入口；首页、学生视图和打印材料无旧版本宣传 |
| 文字与布局 | 中英字号层级、字体和间距一致；360/390/768/1440 px 无整体横向溢出；手机控件易点击 |
| 新生成 | 自定义主题调用真实 AI；失败时给出错误，无固定规则替代；背景、目标和已确认记录进入请求 |
| 结构 | 所有题号、选项、答案、两级提示、解析、题组反馈和已有跳转目标完整 |
| 导出 | 可移植 JSON 不含学生身份、作答历史、访问令牌、请求历史和 API 密钥 |
| 导入 | 无 AI 时可用；缺学生时创建后继续；内容、配置、哈希、完整性与记录纸覆盖得到校验 |
| 冲突 | 重复导入不新增；同编号不同内容或学生、纸张编号冲突被拒绝，数据不被覆盖 |
| 审核 | 导入包也是待审核草稿；批准前不能打印或保存学习记录 |
| 打印 | 题册、核对册、记录纸、教师答案册均可生成；长内容超页报错而非截断 |
| 纸上路线 | 从第 1 组开始，条件可判断，目标确实存在，重试有停止条件；不需中途联网补材料 |
| OMR | 正拍、倾斜、阴影、灰色/彩色/偏心标记、多选、错误编号、倒序多页与同页重扫可检查 |
| 学习记录 | 首次、提示、重试、未知与确认未分配分开；修订可追溯，相同保存不重复计数 |
| AI 总结 | 按当前学生和主题的已确认证据总结，导入文字不当作新学生观察 |
| 移动运行 | Android 和 iOS 均启动内置服务及页面；选择 JSON/照片、保存文件、打印和重启后的记录可用 |
| 文档 | 正式指南和验收与实现一致；历史状态归档；实际未执行的检查明确标注 |

## 实物与真实设备检查

使用准备展示的英文学习包和一份中文包，实际印刷题册、核对册和全部记录纸。检查小字、表格、答案空位、定位标记、页数、颜色对比和装订后的阅读顺序。让使用者走两条不同纸上路线，记录无法独立理解的指引。

至少在一台真实 Android 和一台真实 iPhone 上测试导入、照片选择、系统 PDF 保存、重启和扫描。模拟器启动测试通过后，仍需记录真机系统版本、打印服务、浏览器/系统控件行为和校对结果。

使用合法真实模型连接完成一次英文生成、一次中文生成和一次有确认记录的总结。检查内容与数学/事实答案。没有连接凭据或没有执行的项目标注“未执行”，不沿用历史调用结果宣称本次已通过。

验收记录见 [验证记录](validation.md)。
