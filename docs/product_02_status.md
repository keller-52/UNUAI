# PAPER AI 0.2 实现记录

日期：2026-09-27。基于 `549d1ab` 继续开发，不新增知识单元。

## 本轮实现

| 功能 | 行为 |
|---|---|
| 中英双语 | 教师界面切换；每轮独立选择材料语言；中文/英文题目、提示、规则文字、AI 规划指令、记录纸和学生打印入口。JSON 字段、技术错误和第三方返回模型名仍使用原文，便于调试。 |
| 单元接口 | 题库拆为版本化 JSON，启动加载、校验器注册入口；见单独扩展协议。 |
| 可变学习包 | 每轮 2–4 道题、2n 个节点；沿用一页 OMR-1。按学习天数分配任务日期编号；不是学习时长预测。 |
| 排版 | 按内容块自动增加续页，重新回填跳转页码。超过预算或单块无法容纳则阻止打印；不压小字号。极长内容仍需教师改稿。 |
| 草稿修改 | 教师可编辑标题、规划说明、辅导文字；更新计划哈希；已发行版本禁止修改。草稿可单独丢弃。 |
| 学生状态 | 分别显示独立正确、提示后正确、证据是否不足；每三轮标记复习检查，规则模式优先放入一题旧题；重复题目显式列出。尚无经过验证的长期掌握模型。 |
| 批量工作 | 班级/分组、学生搜索、所选学生依次生成、最近已审核材料合并打印。逐份教师审核保留；某次失败后停止并保留已完成结果。 |
| 生成恢复 | 持久生成任务记录、请求 ID 去重；刷新后查看任务并打开结果。进程重启后运行中任务标记 interrupted，不自动重发付费请求。 |
| 校对草稿 | 浏览器保留未保存的校对字段；恢复时核对服务器修订号。原照片不持久保存；恢复的扫描字段按手动校对再次确认。 |
| 备份恢复 | 完整版本化 JSON，包括历史修订；校验和、引用与答案校验，冲突整体拒绝；不覆盖原数据。恢复前本地数据库快照，新恢复学习包重建学生链接令牌。API 密钥不进入备份。 |
| 一键启动 | Windows/macOS/Linux 脚本启动并打开浏览器；`launch.py --configure` 隐藏输入密钥；失败显示启动问题。仍需 Python 3.10+。 |

## 验证边界

本轮执行 28 项 Python 检查通过，涵盖原核心/HTTP/AI 模拟测试与新增双语、2/3/4 题、备份恢复和修订历史；所有前端模块语法检查通过。未重新进行真实 API 调用、浏览器视觉验收或实拍验证。先前 0.1 的浏览器结果不能等同于本版本验收通过。

## 给本地 AI 的下一次验收

- 新数据库启动；中英界面来回切换，确认表单数据不丢失、内容语言与界面语言互不覆盖。
- 每种材料语言分别生成 2、3、4 道题；检查跳转页码、页数上限、续页和八行记录纸。
- 批量生成后逐份审核；合并打印选中学生的最新已审核学习包与记录纸。
- 草稿修改后旧哈希请求应拒绝；已发行材料不能被编辑或丢弃。
- 生成期间刷新，观察任务状态并打开完成结果；同一请求 ID 不应重复生成。原进程被终止后检查 interrupted。
- 未保存校对后刷新并重新打开轮次；服务器已有新修订时不要恢复旧草稿。
- 下载完整备份，在新数据库恢复，再次恢复应不重复；冲突备份应无部分写入；校验不同轮次与历史修订。
- 检查实拍、人工校对、浏览器双标签页冲突、打印字体与真实 AI 长文本。

旧浏览器长文本用例允许“正常分页”或“明确阻止打印”，不能再固定要求所有长文本都溢出。本轮仍保留单块过长/预算超限的保护。自动分页不拆任意长段落，若后续需要长篇阅读材料，应增加可分割文本块与专用题型。
