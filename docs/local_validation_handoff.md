# 本地 AI 验证交接

> 用户已指定：当前环境无法完成的本地验证，由另一个本地工作的 AI 接手。本文件记录具体步骤与验收标准。请先阅读 `demo/README.md` 和 `docs/demo_status.md`，不要把未执行项目记为通过。

## 已完成与未完成

已执行：21 项 Python 核心／HTTP／模拟 AI 适配测试、JavaScript 语法检查，以及合成图的选框、透视、错包和模糊标记识别测试。记录纸栅格图已人工查看。

未执行：真实浏览器操作与 PDF 分页验收、实际打印及手机照片识别、真实外部模型调用。当前环境的 Playwright 浏览器下载返回站点不可用页面，因此浏览器脚本并未跑通；这不是已经证实的应用错误。真实 AI 测试需用户在本机配置凭据，不把密钥写进仓库或测试报告。

## 1. 启动与自动测试

使用独立测试数据库，避免修改用户正式记录。在仓库根目录运行：

```bash
python -m unittest discover -s demo/tests -p 'test_*.py' -v
python demo/server.py --port 8765 --data demo/data/local-validation.sqlite3
```

另开终端，安装仅用于测试的 Node.js 依赖并执行：

```bash
npm install --no-save playwright @napi-rs/canvas
npx playwright install chromium
node demo/tests/scanner_test.cjs
node demo/tests/browser_smoke.cjs
```

应用本身不需要 npm 依赖。截图／PDF 输出目录可用环境变量 `PAPER_TEST_OUTPUT` 指定；浏览器脚本默认使用 8765 端口。测试会新增虚构学生轮次，可重复运行；测试数据不要作为教育成效证据。

## 2. 浏览器与交互验收

| 检查 | 预期结果 |
|---|---|
| 全新启动、创建匿名学生、诊断留空／作答 | 未作诊断标未知；可以生成第一轮；刷新后数据保留 |
| 加载 Alex 与 Sam，分别生成规则方案 | 前者偏基础支持，后者检查迁移；明确显示未调用 AI |
| 教师审核前后 | 未审核不能发行、扫描评价或打印；审核后包版本固定 |
| 打开三种打印视图 | 学生册、记录纸、教师答案相互独立；页面加载没有 JS 错误 |
| 上传本包样张并识别 | 编号匹配；访问顺序、首次答案、提示一致；所有值仍需人工确认 |
| 人工校正一个扫描值并保存 | 导出中有原始识别值及修正字段；再次修改产生修订 |
| 重复保存同一记录；两标签页保存旧版本 | 同一记录不重复累计；旧修订冲突明确提示 |
| 第二轮生成 | 输入包含第一轮证据，题目与理由可解释；未知或路径错误不会直接触发进阶 |
| 切换学生与历史轮次 | 页面、扫描目标与学生一致，不把旧包结果留在新学生名下 |
| 390px 与桌面宽度 | 核心按钮可操作，无整页横向溢出；表格可局部横向滚动 |
| 学生打印视图 | 返回数据不含 `correct_option` 和题目隐藏答案字段；允许的补救讲解仍存在 |

注意：学生链接是本机单教师应用的打印视图，不是完整账户隔离。不要将它当作可公网部署的权限系统。

## 3. PDF 与实际打印

选择 A4、100%／实际大小、关闭浏览器页眉页脚。检查：学习册恰为 3 页、记录纸 1 页、教师版 1 页；无文本裁切、脚注覆盖、意外空白页；任务编号和跳转页码正确；记录纸四角与顶部光学编号完整。

还要测试较长标题与辅导文本。页面有越界检测：若超出边界应禁止打印并提示，不应静默裁切。当前尚无教师草稿编辑器，可在隔离测试夹具中构造长文本，不修改正式已发行包。

至少实际打印一次，填出一条错误补救路径与一条全对路径，再用手机拍照。照片传至运行程序的电脑；本版只监听本机，不支持手机直接访问电脑服务。

## 4. 实拍扫描

按以下条件逐张测试并记录真实结果：正面清晰、倾斜、轻微阴影、浅色填涂、多选、遗漏、错误包、部分角点裁切。自动定位失败时尝试按左上、右上、右下、左下点击黑块中心。

逐字段人工转录为参考，分别记录自动正确、拒识、误识、校正后正确与校对耗时。读不清应提示或留未知；不能为了“通过”把错误自动填成某个选项。当前不支持手写 OCR、自动旋转、PDF 上传或多页回收，相关输入不属于已承诺能力。

## 5. 真实 AI 接入

由用户在本地界面配置其提供商、模型和密钥。实际执行一次 Live AI 生成，核对题目来自题库、引用存在、说明适切、请求包含诊断题上下文和历史证据、返回与运行记录一致。对第一轮记录进行确认后，再执行第二轮，比较差异。

用错误模型名／无效凭据测试错误提示，确保不会改用规则结果冒充 AI。JSON 修复上限等行为已有模拟传输测试，不需要为了测试反复产生不必要的付费调用。

## 6. 回写结果

请在 `docs/local_validation_results.md` 记录：日期、操作系统、浏览器版本、代码提交、测试命令、已通过／失败／未执行列表、必要截图或 PDF 的位置、实际发现与修复、仍待验证的项目。只保存虚构／获准脱敏数据，不提交密钥、数据库或真实学生原图。

若修复代码，增加对应回归测试，再更新 `docs/demo_status.md`。合成扫描通过不能替代真实照片结果，AI 协议模拟通过不能替代真实调用，技术测试通过不能替代学习成效实验。
