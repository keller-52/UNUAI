# 研究问题、实验与证据计划

> 本文是待执行研究计划，所有结果暂缺。模拟数据用于验证流程，不能证明真实学习效果。研究对象、样本量与时间由团队和学校在执行前确认。

## 1. 研究问题与可验证假设

| 问题 | 首版怎么验证 | 可支持的结论边界 |
|---|---|---|
| 教学逻辑能否在纸上执行？ | 真实打印、让使用者按分支完成、记录误跳与求助 | 可用性与技术可行性，不直接等于提升成绩 |
| 记录纸能恢复哪些事实？ | 人工转录作为参考，与自动识别和确认后记录分别比较 | 答案、提示自报、路径恢复能力；不等于读取思维过程 |
| AI 是否有实质作用？ | 保留真实请求、响应和两种学生证据下的不同计划 | 证明系统确有 AI 规划；效果好坏还需实验 |
| PAPER AI 是否改善学习？ | 与普通纸张及在线 AI 进行匹配内容的比较 | 小样本只能给探索性结果，避免普遍推广结论 |
| AI 最少多久介入？ | 在较长研究中比较多种间隔并检查保持效果 | 短期 Demo 不能得出最低有效频率 |

## 2. 分阶段实验

**A. 工程验证（首版必做）**：用明确标为 synthetic 的学生和答案，跑通两轮；检查分支、版本、扫描异常和 AI 失败处理。输出可复现操作记录。

**B. 小规模使用测试（有条件开展）**：在学校取得适当同意后，邀请同学／教师试用，记录是否能理解指示、找到提示、正确填写记录纸，以及教师校对与打印负担。记录实际人数与条件，不预写结果。

**C. 教育效果试验（资源允许时）**：开展前测、学习、后测，若时间允许增加延迟测；三组使用同知识目标、相近难度与总学习时长。预先确定主要指标及比较方法。

**D. 接入间隔研究（后续）**：比较每日、每三日、每周等设置，保持总学习时间和内容覆盖可比。第一轮短期试验不强行塞入所有间隔。

## 3. 三组对照

| 组别 | 学习条件 | 公平比较要点 |
|---|---|---|
| 静态纸张组 | 统一材料，预设固定顺序 | 同知识目标、题量与可用学习时间 |
| PAPER AI 组 | 轮次个性化＋纸上分支＋记录回收 | 记录实际分支与教师帮助 |
| 在线 AI 组 | 学习时可访问 AI 辅导 | 固定模型和内容范围，记录接触时长 |

优先按前测水平分层后随机分配；人数不足时可做匹配或交叉试验，但需报告选择偏差、顺序效应和题目记忆影响。三组前后测使用同等难度的新题，不能直接拿训练题重复作答代替迁移效果。评分尽量采用预先确定的标准，条件允许时隐藏组别。

若实际仅能完成 A 阶段，应明确报告“模拟教育情境下的基本技术测试”；若只完成 B 阶段，报告可用性结果，不写成因果学习收益。

## 4. 指标与计算口径

| 指标 | 计算／采集方式 | 需要注意 |
|---|---|---|
| Learning Gain | 后测百分制分数 − 前测百分制分数 | 同等难度；记录基线与每名参与者数据 |
| Retention | 延迟测成绩，或延迟测减后测 | 没有延迟测就标未测量 |
| Independent Accuracy | 无提示首次正确题数／有可用首次记录的题数 | 提示未知不并入无提示 |
| Trace Recovery Accuracy | 自动正确读取字段数／预先定义的可评价字段数 | 人工确认前、确认后分别报告，并报告拒识率 |
| Path Recovery | 访问序列与人工参考一致的记录数／可评价记录数 | 报告漏填，不能只统计顺利案例 |
| Review Burden | 每张纸校对时间、修正字段数 | 自动化收益须扣除人工校对成本 |
| AI Contact / Screen Time | AI 接触时长与屏幕使用时长分别记录 | 学生和教师分别统计，不能混用 |
| Resources | 实际数据传输量、API 用量、打印页数、墨耗／成本估算、教师时间 | 没测能源不声称节能；打印也有资源成本 |
| Package Validity | 验证通过包数／全部生成包数，及修复次数 | 记录初次通过率，别只报告修复后成功 |
| Personalization | 计划是否对应证据、补救后新题表现、相对固定策略的比较 | “个性化保持”尚无预定成熟量表，不伪造单一分数 |

统计报告展示实际 n、缺失值、退出情况、分布或个体变化与不确定性。探索性小样本以描述性证据为主；不能仅凭平均数变化宣布显著优越。等效／不劣于在线 AI 的结论需要预先定义界值与充分样本，首版不默认声称。

## 5. 有意义的技术测试用例

| 场景 | 预期行为 |
|---|---|
| 选项为典型错误 | 按纸上指示到相应补救节点，最终可结束 |
| AI 引用不存在节点／给出环路 | 被验证器阻止发行 |
| 数学答案错误 | 验算／教师审核失败，不能打印为批准版 |
| 倾斜、缩放、黑白打印 | 定位成功或明确要求重拍，不默默读错 |
| 多选、空白、浅色涂选 | 异常或 unknown，人工确认 |
| 错包版本、缺页、重复扫描 | 阻止误合并、请求补页、不重复累计 |
| 实际路径跳错 | 保存事实并提示，不伪造合法路径 |
| 网络中断或 AI 返回非法 JSON | 草稿保留，可重试；不冒充成功 |
| 超页数、中文／英文长文本 | 检出溢出，重新布局或规划 |
| 学生下载打印数据 | 不含教师答案与其他学生内容 |

至少做一次实际打印—填写—拍照—校对—再生成测试；仅在屏幕上读 PDF 不足以证明纸面闭环。

## 6. 相关工作与原创性证据

检索并比较自适应练习册、分支教学／程序教学、AI worksheet 生成、OCR 批改、离线 AI Tutor 与低设备教育方案。对每个实际查到的来源记录：题名、作者／机构、年份、链接、真实功能、与本方案的重合与差异。检索尚未完成前，不使用“首创”“首次”等结论。

比较维度包括：纸上是否有教学分支、是否按学生个性化、是否恢复学习轨迹、是否基于轨迹更新、设备依赖、已验证效果。研究亮点候选是这些机制的闭环组合与接入间隔问题，而非宣称分支纸张本身从未存在。

## 7. 证据保存与报告边界

工程证据：版本号、运行环境、输入输出、校验日志、纸质样本与脱敏照片。学习证据：研究设计、匿名记录、评分标准、前后测、异常说明。开发证据：学生贡献记录、工具使用、模型版本、提示词与第三方来源。

真人测试与拍摄按学校流程取得适当同意；公开展示使用虚构或获准脱敏材料，避免未获准的人脸、姓名和手写个人信息。报告说明目标地区尚未实际验证、印刷配送成本、提示使用自报偏差、记录误填、AI 内容错误与有限样本等限制。
