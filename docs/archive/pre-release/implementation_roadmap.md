# PAPER AI 当前任务清单

更新：2026-09-28。当前版本 0.6；本次不修改版本号。实现和验证记录见 [当前进度](product_06_status.md)。

## 已实现

- 本地单教师闭环：AI 讲解/出题 → 审核 → PDF → 离线学习 → 扫描校对 → 学情总结 → 下一轮。
- 自定义主题，默认 3×10 题，自由设计的三栏离线反馈；双语界面和材料。
- 主流平台协议预设、PDF 下载及打印快捷键降级、多页 OMR、记录修订和备份。
- 首页概论与三个工作区；统一纸张色背景、双语字号/留白、移动端布局。
- 每题答案括号、每条提示勾选框、正文两字缩进。
- 一文一理展示题库位置已预留，内容待选。
- 多轮真实提示词测试；按失败类型改进，并对未来题条件进行局部反馈修复。

## 剩余事项

1. 持续观察生成质量与真实失败样本；自由分流的教学语义仍由教师审核。
2. 新版纸张与原问题电脑 PDF 导出复测；扫描阴影、翘曲及校对耗时统计。
3. 中英文完整实物闭环、各平台实际账号测试，汇总验收报告。
4. 用户确定一文一理两个展示知识点后，再制作并审核其预制背景和参考题。
5. 需要提交项目时，再准备正式展示材料与研究证据；竞赛事项以竞赛文档和官方最新信息为准。

## 已取消

**不再扩展通用知识单元内容。** 旧接口只作兼容保留，不再把“增加知识单元”列入未来工作。教师自定义主题不受这个决定限制。

功能变更同步 [本地 AI 验收指南](local_ai_test_guide.md) 与 [人工操作指南](manual_operation_guide.md)。
