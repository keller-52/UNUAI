# 一文一理展示题库预留

当前只预留两个位置，尚未选择知识点，也没有内置示例题冒充正式展示内容。

- 界面入口：生成题目内容 → 展示预制题库（默认折叠）。中文/英文共用同一份结构与样式。
- 文件：`demo/showcase/manifest.json`，`schema_version: 1`。
- 固定位置：`humanities`（人文）与 `science`（理科）。
- `label`：`zh`、`en` 两种名称；`status` 当前为 `reserved`。
- `topic`、`background` 当前为 `null`；`reference_questions` 当前为空数组。
- `/api/bootstrap` 的 `showcase_slots` 提供位置数据；当前卡片为信息提示，不可启动空题库生成。

后续由用户确定两个知识点后，再填入经过审核的背景与参考题，并接入相应使用流程。普通教师仍可填写任意主题，让 AI 自主生成；本次稳定性实验的虚构背景不是正式展示题库。

根据 2026-09-28 最新决定，**通用知识单元内容扩展已取消，不再列为后续任务**。现有旧单元读取能力仅用于兼容历史学习包；两个展示位置不等于重新启动知识单元扩展工程。
