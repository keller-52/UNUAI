# AI 自主出题与参考题库（0.3）

需求：AI 根据教学目标与学生实际记录决定题目；题库保留，作为可参考、可引用的资源，不是必须从中选题的菜单。

## 决策流程

教师目标/年级/语言/页数与题量 → 学生诊断、确认评价、提示使用、历史题目全文 → AI 自主设计 → 结构/数学校验 → 教师审核 → 冻结学习包 → 打印/扫描/下一轮。

真实模式允许全部新题、全部题库题或混合，没有程序设定的新题/旧题比例。引用旧题可用于复习，设计新题可针对具体错误改变符号、系数和选项。规则演示模式仍使用题库，而且始终明确标注未调用 AI。

## 背景解释和提示词

实际运行读取 [author_lesson.md](../demo/prompts/author_lesson.md)，不是仅供阅读的设计稿；`PROMPT_VERSION=paper-author-2`。每次成功生成保存完整系统提示词、输入、响应、校验反馈、用量与结束原因，便于复盘。

提示词包括：

| 部分 | 具体要求 |
|---|---|
| 项目背景 | 间歇接入 AI、纸上独立执行；离线期间无法由模型判断任意手写答案 |
| 学生证据 | 区分首次错误、重试正确、提示后正确、未知与路径异常；不将启发式标签当确定诊断 |
| 出题自由 | 根据目标自主设计，也可引用题库；无来源比例限制，说明选择依据 |
| 难度与顺序 | 弱证据先探查，针对错误设计区分性任务，条件支持再迁移；考虑复习与非故意重复 |
| 题目组成 | AI 决定系数、正确/错误选项、题面文字、两级提示、解题说明、逐题设计理由 |
| 纸面执行 | 当前 2–4 题、最多八节点、首次答案分支、提示等级与输出长度；不编造页码 |
| 输出合同 | 一个完整 JSON 示例、必需字段、题库引用和新题 ID、证据引用要求 |
| 自检与修复 | 检查算式、唯一答案、干扰项与解析；收到具体错误时修复，最多额外请求一次，不自动切换规则结果 |

输入增加年级、单元能力范围及历史题目全文。生成题 ID 只在学习包内唯一，历史证据仍以 package ID + task ID 引用；不能把另一轮的 N1 当成同一道题。参考题库中全部非诊断题随请求提供，不要求 AI 使用。

## 输出与保存

保留 `question_ids` 作为本轮教学顺序，同时增加 `generated_questions`。

- `question_ids` 中 F/T 等现有编号表示引用题库；N1、N2 等表示本轮新题。
- `generated_questions` 保存所引用的新题完整定义，无未使用新题、无重复 ID。
- 新题包含 `equation`、`prompt_template`、`options`、`correct_option`、`hints`、`explanation`、`misconception_options`、`design_reason`。
- 编译后每题保存 `origin=ai_generated` 或 `bank`。教师审核界面/教师 PDF 显示来源和新题设计理由。
- 保留旧的题库提案格式，旧学习包仍可读取；新题内容随学习包和备份保存，不静默加入全局已审核题库。

完整可执行输出示例见实际提示词。学生接口移除答案、方程验证元数据与设计理由；补救节点中有意提供解法，这是教学内容。

## 当前数学范围与检查边界

依照“不扩展知识单元”的决定，首个适配器仍处理 `a*x+b=c`，整数系数、非零 a、唯一整数解，数值有界。AI 自行决定 a/b/c，程序只将其插入 AI 题面中的 `{equation}`，不会偷偷换成内定题。

程序能检查：结构、题量、ID、参数范围、整数解、A/B/C 数值不同、指定答案确实成立、错误选项的 sign_change 标注是否符合其数学定义、提示数量/长度、证据引用与图结构。正文解析是否教学恰当、文字是否与题意完全一致仍需教师判断；提示词不能保证永远正确。

这不是支持任意学科/任意开放题的生成器。进一步支持分数、复杂方程、应用题或别的学科，需要新的表示与验证适配器。当前改动实现“在现有单元内自主出题”，并未增加新单元。

## 校验与验收记录

本轮新增混合来源、全新题、错误答案/误区拒绝、学生答案投影、备份与历史上下文检查。软件验收结果见下方最终记录；0.2 浏览器/PDF 验收是旧版本证据，新题可能带来更长文字，须本地继续验证新题打印、教师审核和实物链路。

早期真实试调用因规划理由长度/字段合同和错误的 sign_change 标注被两次校验拒绝，未发行无效包。随后改进完整 JSON 示例与具体到题号/选项的修复反馈；不将这些失败隐藏为成功。
