## 1. 下载、启动与配置

下载 [main 完整 ZIP](https://github.com/keller-52/UNUAI/archive/refs/heads/main.zip)，全部解压到新目录，先保留原数据和私有配置。不要只下载 HTML，也不要覆盖唯一的原始数据库。需要旧记录时先从旧程序下载备份，再到新程序恢复。

电脑安装 Python 3.10+；Windows 双击 `demo/start-demo.bat`，macOS/Linux 执行 `sh demo/start-demo.sh`。浏览器访问 `http://127.0.0.1:8765`。打不开时，在仓库根目录运行 `python demo/launch.py`（Windows 也可用 `py -3`）；端口占用时改用 `--port 8766`。保留服务终端。

界面选择中文用于调试、英文用于展示。界面语言与学习材料语言独立；切换界面不会翻译教师输入或 AI 已生成的文章。

点击“配置 AI”：

1. 选择提供商，自动填写该平台地址和协议。
2. 填写账号可用的模型 ID 和该平台密钥。Azure 要把示例资源地址改成自己的地址；阿里云按地域/业务空间使用控制台地址。更换平台时重新填写对应密钥，不能把 DeepSeek 密钥用于其他平台。
3. JSON 输出模式先用“自动”。模型不接受 JSON 参数时可选择“仅提示词约束”；仍要求模型返回完整 JSON。不要用此设置掩盖无效密钥或模型不存在。
4. 保存。网页保存到当前服务会话；需重启后保留时，在本机私有 `demo/data/provider.json` 填入 `provider`、`protocol`、`base_url`、`model`、`json_mode`、`api_key`，参考 `demo/provider.example.json`。密钥不要发到仓库、截图或报告。

支持平台和协议的准确范围见[平台表](product_05_status.md#平台范围)。配置存在不等于调用成功。应用不需要额外 AI SDK；PDF 直接导出需要本机安装 Chrome 或 Edge。

## 2. 自定义主题、生成与审核

首页保留宣传和流程概论。点击左侧“生成题目内容”，创建/选择匿名学生，填写主题、完整背景、前置知识、教学目标和范围。新版页面只提供 AI 自定义主题生成，不再显示旧方程/规则演示入口。每组 5–10 题，2–3 组，默认 3×10。首次快速检查可用 3×5，最终再复测默认 30 题。

AI 先讲解，再出题，并在核对册用“选择情况｜情况分析｜跳转内容”简表给出结论和下一步。条件只能用已经完成的题，跳转明确写题组/题号或结束；重做要有停止条件。现在不要求分流 JSON 固定排序、分数区间穷尽或只能向后跳；AI 可按正确数、特定错题、知识点理解等自由设计。教师检查所有目标确实存在、学生知道何时结束，避免无休止重复。

讲解正文统一首行缩进两个字宽；提示编号与文字同排、末尾带 □，各题用横线分隔；题目末尾带（　　）作答区。讲解、例子、提示、解析和分流可用 Markdown：短段落、`## 小标题`、`**重点**`、编号步骤、简单表格、行内代码。数学用 Unicode 符号或行内代码，例如 `2x + 3 = 7`、≤、√；本版没有完整 LaTeX 渲染，不要把 `\frac` 等源码当作已支持公式。

逐题审核事实、选项、答案、解释和难度，再批准冻结。必要时编辑完整草稿 JSON；文本中的换行需要合法 JSON 转义。系统只做基本结构与引用检查，不能替代教师审核。生成失败会说明，最多两次模型尝试，不会暗中返回规则包；保留错误信息后再修改，不连续无目的重试。

## 3. 一键下载 PDF 与打印

同一学习包分别打开：讲解与题册、提示与核对册、全部记录纸、教师答案指南。预览全部页面后：

- **一键下载 PDF**：程序调用电脑已安装的 Chrome/Edge，在本机生成并下载 PDF，不经过当前浏览器的系统打印对话框。首次导出可能需数秒，请等按钮恢复。
- **打印/保存 PDF**：打开浏览器打印对话框，可选择打印机或另存 PDF。
- 按钮无响应或不可用：页面持续显示 **Ctrl+P**（Mac 为 **Cmd+P**）提示。若页面有内容超长或预算错误，先修正，不用快捷键强行打印截断内容。

无法找到浏览器时，安装 Chrome/Edge，或把 `PAPER_AI_BROWSER` 环境变量设为其可执行文件完整路径后重启服务。例如 Windows Edge 常见路径为 `C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe`，以本机实际位置为准。不要把目录当作可执行文件。导出失败仍可用 Ctrl+P。

打印 A4、100% 实际大小、关闭页眉页脚、单面、每张一页。记录纸每页最多 8 题：15 题 2 页、20 题 3 页、30 题 4 页。题册/核对册页数随内容变化。检查黑色定位块和顶部编码完整，无裁切、叠字或表格越界。

题册与核对册分开装订；按组折叠或封住核对页，避免提前看到答案。开始前一次发齐所有可能使用的题组、核对册和全部记录纸，不中途补印或联网领取。

## 4. 学生离线操作

先阅读讲解，从第一组开始，在每题末尾括号填写首次答案。用过提示就在对应提示末尾 □ 打钩；整组完成后将答案和最高提示等级转填记录纸，再立即打开本组核对页。不要将后续重试答案覆盖首次答案。按 AI 印在核对册里的具体指导选择下一组、回看讲解、补强或结束，不机械按印刷顺序全做。

首次答案不能擦掉；提示 0 表示确实未使用，1/2 表示最高提示等级；空白是未知。重试单独记录，不能反向覆盖首次作答。未分配到的题组留空，最后交回全部记录纸，包括空页。全过程无需联网或再次调用 AI。

若指导含糊、跳转不存在或不知何时结束，记录为教学设计缺陷，回到教师审核修订；软件不再把自然语言当成已验证的确定性程序。

## 5. 最后扫描与校对

进入“扫描上传”。每页拍一张正向原图，四角与顶部码都完整。传到电脑，选同一 package ID/版本后逐页上传；自动定位不对时，手动依次点左上、右上、右下、左下定位块中心。

编码条现在会做小范围偏移搜索并校验校验码，不会按当前学习包猜编号；本次两张原始照片已在图像回归中得到一致的 Q9/Q10 结果。新版按内圈填涂面积识别：与附近纸色有足够色差、面积超过一半即可选中，不要求圆心必须涂黑。仍建议深色笔清晰填涂；同字段两圈都超过一半会提示不确定，不自动猜选。阴影、极浅笔迹、错角点仍可能失败，保留原图并校对。

每读一页先保存原始识别截图，再读下一页，检查其他页记录仍保留。全包核对后：

- 自由指导包中，空白题先显示“未作答或已跳过”，不计为错误。
- 对照实际纸上路线，在“确认未分配的题组”勾选确实没有分配的组，再确认保存。有任何答案或提示的组不能同时标跳过。
- 无法判断的空白保留未知，不凭分数猜测学生去了哪里。已录入的首次/重试分开保存。

需要重试同一页可重新上传；错包应拒绝。保存后进入“学习总结”，选择轮次，点击“根据最新记录总结”，查看“情况、措施”；随后到“生成题目内容”安排同主题下一轮。“学习轮次”折叠区可打开以前的包；“批量工具与备份”折叠区提供批量生成、合并打印和备份恢复。旧已发行记录仍可打开，不删除用户数据。手机不能通过它自己的 127.0.0.1 访问电脑，当前仍是先把照片传到电脑；不支持 PDF/手写 OCR 作为照片识别输入。

## 6. 本轮复测交回什么

重点复测本机打印按钮与直接 PDF 导出，以及中英各一份长讲解。已提供的两张照片可复用；另补拍轻微翘曲、灰笔/蓝笔与阴影样本。检查提示编号不单独占行、勾选框不被裁掉、题目有答案括号、分流表不引用未做题。至少保存两种不同纸上路线、默认 30 题包的四页记录、直接导出的 PDF、Ctrl+P 保存的 PDF、逐页照片、人工真值、原始识别与校正结果、耗时和具体失败提示。

使用[记录模板](manual_physical_test_record.md)；原始识别率和人工校正后正确率分开统计，失败样本保留。不要上传密钥或私有 provider 配置。新阈值通过合成图不等于所有实拍都通过；用户上一版实测完成也不自动代表本版复测通过。

新增审核提醒：若三栏分流表的“选择情况”明确引用本组之后的题号，页面会显示题组/题号警示。请在草稿 JSON 中修改条件，再保存审核；这是辅助提醒，不执行分数规则，也不证明所有自然语言逻辑已正确。

“根据最新记录总结”只分析已保存证据，不生成新题；需要新题请回到“生成题目内容”。
