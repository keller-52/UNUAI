# PAPER AI 0.4 人工操作指南

> 更新：2026-09-27。本文是当前版本的人工操作主指南。旧的 `manual_physical_validation.md` 仅保留 0.2 历史流程，不再作为 0.4 的操作依据。
>
> 配套验收标准见 [本地 AI 测试与验收要求](local_ai_test_guide.md)，当前实现边界见 [0.4 进度](product_04_status.md)。

## 1. 当前流程

PAPER AI 0.4 的核心不是“每做一题就问 AI”，而是把未来一段时间的教学逻辑一次编译到纸上：

```text
教师设定主题与目标
→ AI 讲解 + 预生成多个题组 + 预生成分流规则
→ 教师审核
→ 一次打印全部材料
→ 学生离线完成一个题组
→ 完成整组后打开对应核对页
→ 按首次答案统计与错题规则跳转到下一题组
→ 重复，直到 END
→ 最后回收并逐页扫描
→ AI 根据已确认记录生成学情总结与下一轮
```

学生离线阶段不需要联网、不需要再次调用 AI，也不需要上传中间作答。所有可能被分流到的题组、核对内容和记录纸都必须在开始前备齐。

## 2. 启动与 AI 配置

1. 下载并完整解压仓库 main 分支源码。
2. 安装 Python 3.10+。
3. Windows 双击 `demo/start-demo.bat`；macOS/Linux 运行 `sh demo/start-demo.sh`。
4. 浏览器打开 `http://127.0.0.1:8765`。不要直接打开 `index.html`。
5. 自定义主题必须使用真实 AI。点击明显的 AI 设置入口，配置兼容 Chat Completions / JSON mode 的服务；当前已验证 DeepSeek 接入。
6. 配置状态只表示参数存在，不代表真实请求一定成功。真实调用失败时应显示错误，不能静默切换成规则演示。
7. 密钥只放本机私有配置或环境变量，不写入仓库、截图、报告或备份。

主流平台原生 API 适配仍是延期项；当前不能宣称“所有主流平台均原生支持”。

## 3. 创建一个自定义学习包

教师选择“自定义主题”，填写：

- 学科 / 主题；
- 学生年级或预期基础；
- 背景材料；
- 教学范围与明确目标；
- 不希望超出的内容；
- 材料语言；
- 每题组题量与题组数量。

当前推荐：

- 快速工程测试：3 组 × 5 题；
- 正式默认：3 组 × 10 题；
- 每组必须保持 5–10 题。

AI 先生成简短讲解，再设计各题组。每个题组至少要有：

- 稳定组号；
- 题组名称；
- 目标知识点；
- 难度；
- 5–10 道题；
- 完成本组后的反馈 / 分流规则。

题库只可作为参考，不得把“自定义主题”偷偷限制回旧的一元一次方程单元。

## 4. 教师审核：没有审核就不发行

教师在草稿阶段逐项检查：

1. 讲解是否事实正确、适合目标学生。
2. 每道题是否有明确答案，答案与解析是否一致。
3. 每组题量是否为 5–10。
4. 第一组至少存在两个有意义的后续去向，否则不能体现自适应。
5. 分流条件按从上到下的顺序执行，第一条匹配即生效。
6. 可以按本组首次正确数分流，也可以优先依据指定错题 / 知识点错误分流。
7. 兜底规则必须覆盖从 0 到满分的所有情况。
8. 所有目标必须是已经印刷的后续题组或 `END`。
9. 禁止循环、悬空目标和永远无法到达的题组。
10. 题组编号和 Q 编号必须稳定，不依赖最终 PDF 页码。

必要时直接编辑讲解、题目或分流 JSON。只有校验通过并人工审核后才批准 / 冻结。

## 5. 一次打印哪些材料

一个学习包至少包含三类纸张：

| 材料 | 给谁 | 内容 |
|---|---|---|
| 学习册 | 学生 | 讲解、题目、题组编号与操作说明 |
| 独立提示 / 核对册 | 学生，但按组封闭 | 提示、首次答案核对、解析、分流规则 |
| 记录纸 | 学生 | 首次答案、提示、重试、题组 / 题号、页码和识别信息 |

教师答案 / 审核版可另行保存，不能与学生题册混印。

打印建议：A4、100% / 实际大小、关闭浏览器页眉页脚。核对册可按组折叠、装订或封页，并明确写“完成本组后再打开”。

**所有可能使用的题组必须在离线学习开始前一次发齐。**

## 6. 学生纸上操作

每个题组严格按以下顺序：

1. 阅读当前题组要求。
2. 完成该组全部 5–10 题。
3. 在记录纸保存每题的**首次答案**。
4. 整组完成后才打开该组核对页。
5. 统计首次正确数，并记录首次答错的题号 / 对应知识点。
6. 从上到下寻找第一条满足的分流规则。
7. 跳转到指定题组，或在 `END` 结束。
8. 若允许提示或重试，必须和首次答案分开记录。

重要规则：

- 不按印刷顺序把所有题组都做完，只做分流实际到达的组。
- 重试答对不能覆盖首次错误，也不能反过来改变已经确定的本次分流。
- 没被路线分配到的题是“未分配 / skipped”，不是漏答或错误。
- 因记录缺失而不能确定的字段应保留“未知”，不能自动按错处理。

## 7. 多页记录与回收

0.4 允许多页记录纸。每页都有自己的识别信息，回收时必须包含所有页，包括完全空白但属于该包的页。

拍照要求：

- 深色笔清晰填涂；
- 尽量平拍；
- 四角定位块完整；
- 不裁去顶部编号；
- 一页一张原始照片；
- 不先用聊天软件压缩再作为唯一证据。

回到同一学习包逐页上传。每上传一页后检查：之前已确认 / 已读取的其他页记录仍然保留。原始识别结果先保存证据，再做人工校对。

合理跳过的题应显示为未分配；应完成但读不清的题保留未知。不要为了让统计“好看”而把未知改成错误或正确。

## 8. 学情总结与下一轮

只有确认保存的记录才进入 AI 学情总结。

检查总结是否：

- 只引用当前学生、当前主题的已确认记录；
- 区分首次正确、提示后正确、重试正确、未分配和未知；
- 能指出具体题组 / 题号作为证据；
- 不把单次错误写成已经证实的长期误区；
- 不混入旧主题的一元一次方程标签；
- 新记录保存后，旧总结会失效或明确需要重新生成。

随后生成同主题下一轮。下一轮不要求机械“变难”，而应根据证据选择基础巩固、中档题、进阶题或特定知识点补强。

## 9. 演示时建议走两条路线

至少准备两个匿名测试学生或两份独立测试记录：

- **补强路线**：第一组出现目标错误 → 进入基础 / 特定知识点补强组；
- **进阶路线**：第一组表现较好 → 进入中档 / 进阶组并最终 END。

这样能直接展示“同一份预印纸包，不同学生在没有 AI 在线的情况下执行不同教学路线”。

## 10. 当前不能宣称的内容

在对应证据完成前，不应宣称：

- 0.4 已完成全部浏览器 / PDF / 实物验收；
- 任意学科生成内容无需教师审核；
- 多页实拍扫描已经达到某个固定准确率；
- 默认 30 题对所有主题 / 语言 / 模型都稳定；
- 已支持所有主流平台原生 API；
- 技术测试证明了真实学习增益或长期掌握。

详细通过门槛与测试矩阵见 [本地 AI 测试与验收要求](local_ai_test_guide.md)。
