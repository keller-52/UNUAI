# 研究与参赛材料

## 研究目标

验证 AI 教学策略能否预先写进纸张，在 AI 离线期间被学生正确执行，并通过纸面记录支持下一轮调整。工程可运行、实物可用和教育效果是三个不同层次，应分别报告。

| 层次 | 测试方法 | 可支持的结论 |
| --- | --- | --- |
| 工程 | 学习包生成/导入/审核、四类打印材料、扫描、记录保存、移动启动 | 软件流程与文件格式可运行 |
| 可用性 | 实际打印，让学生按纸上指引完成路线；记录歧义、求助与教师时间 | 指引可执行性和操作负担 |
| 扫描 | 实拍照片与人工真值对照；原始识别与人工修正分开保存 | 样本范围内的识别结果与校对负担 |
| 学习 | 条件允许时前测、学习、后测及延迟测，设置可比对照 | 探索性学习变化；小样本不作普遍因果推断 |

关键指标包括真实生成成功率与修复次数、离线指引执行错误、原始 OMR 正确字段比例、人工校对时间、首次答案正确数、明确无提示作答比例、材料页数、API 次数和费用。未测量的指标不写成结果。

## 正式展示

提前使用真实 AI 生成并审核材料，导出学习包备用。现场可导入这些材料，演示审核、打印、纸上路线、照片扫描和记录回收；随后在网络允许时调用 AI 总结或生成下一轮。展示中明确区分“复用已有材料”和“本次调用 AI”。

导入的旧学情文字是材料快照，不作为新学生的学习事实。下一轮依据本机当前学生已确认的记录。测试夹具、合成照片和模拟答案只用于工程验证，不作为真人学习收益证据。

## 参赛交件

2026-10-01 对照 [澳门电脑学会官方章程](https://www.mcs.mo/articles/104)。以主办方最新原文及报名系统字段为准。

| 项目 | 要求 |
| --- | --- |
| 语言 | 报名、作品内容、附件、海报、影片字幕、简报和答辩使用英文 |
| Project Introduction | 建议不超过 2 页，说明问题、用户、功能、AI 方法、创新与影响 |
| Research Report | 建议 6–12 页，包含方法、来源、测试、结果、限制、隐私与参考资料 |
| Poster | 直向 0.8 m × 1.1 m |
| Demonstration Materials | 照片及不超过 5 分钟的英文影片 |
| 文件 | 文字与海报为 PDF，每个不超过 50 MB；视频按报名系统要求提交 |
| 报名交件截止 | 2026-10-09；后续安排查看官方页面 |

作品需要实际运行的 AI 功能及基本测试。公开代码与 APK/IPA 是技术交付物，不能代替要求的英文报告和展示材料。报告说明模型、提示词、第三方工具、AI 辅助开发及学生实际完成的工作，并准确标注已完成和未完成的验证。
