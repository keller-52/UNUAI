# PAPER AI 项目概述

**PAPER AI 将 AI 设计的教学内容和下一步策略编译成纸质学习包。学生在纸上持续学习，教师在回收节点确认记录，AI 再调整下一轮。**

英文标题：**PAPER AI: Compiling Adaptive AI Education into Paper**。

## 解决的问题

持续在线的 AI 导学通常依赖学生设备、网络和模型访问。PAPER AI 将 AI 接入集中在材料准备和记录回收时段，让两次接入之间的讲解、练习、提示和反馈在纸上完成。应用面向设备或网络有限的教学环境，也适合希望减少学生屏幕时间的学校。

## 完整流程

教师输入主题、来源背景与目标；AI 生成讲解、2–3 个题组、每组 5–10 题，以及独立的提示、答案和下一步指导。教师审核后，将全部题册、核对册和记录纸提前打印。

学生先记录首次答案，整组完成后核对，按纸上指引选择继续、补强、重试或结束。没有分配的题组保持空白。学习结束后，教师上传记录纸照片，校对识别结果并确认记录；AI 据此生成总结或下一轮材料。

## 正式版功能范围

| 能力 | 正式版行为 |
| --- | --- |
| 内容生成 | 根据教师自定义主题、背景、目标和已确认记录调用 AI |
| 学习包导入 | 读取已生成的完整学习包，经校验与审核后使用 |
| 学习包导出 | 单独保存可移植材料，不携带学生作答记录和密钥 |
| 纸质执行 | 全部讲解、练习、提示和反馈在开始前印好 |
| 记录回收 | 本地 OMR、手动校对、首次答案、提示、重试和未分配题组 |
| 下一轮调整 | 只使用当前学生已确认的学习记录 |
| 中英文 | 界面与材料语言分别设置；正式参赛材料使用英文 |
| 移动端 | 手机内置本地工作区，使用原生文件选择、保存和打印 |

正式版取消预制题库、题库预留位和规则生成入口。导入学习包是复用已有材料的功能，不发生新的模型调用；它不替代项目实际运行的 AI 生成和总结功能。

## 分工和判断边界

AI 设计教学内容和策略。程序检查结构、题号、引用和版本，并执行排版、扫描与保存。教师审核事实、答案、难度和指导是否可执行，确认照片识别结果。

自然语言反馈保持灵活，不强制固定分数区间或固定分支数。程序不会把少量作答等同于稳定掌握，也不会把空白答案自动计错。首次答案、提示支持、重试和未知记录分别保留。

当前工程验证证明软件流程可运行；真实纸张可用性和学习效果仍需按 [研究计划](research_submission.md) 独立验证。
