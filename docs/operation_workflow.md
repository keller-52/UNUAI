# PAPER AI 当前操作流程与纸张设计

> **文档分类：当前文档。** 更新：2026-09-28。本文解释 0.5 的概念流程；实际按钮级操作见 [人工操作指南](manual_operation_guide.md)。

## 1. 一轮学习的完整闭环

```text
教师选择学生/主题/目标
→ AI 生成讲解、题目、核对内容和自然语言 guidance
→ 程序做最小结构检查
→ 教师逐题与逐组审核
→ 冻结学习包
→ 一次发齐全部纸张
→ 学生完成一整个题组
→ 记录首次答案
→ 打开该组核对页
→ 按预写 guidance 选择下一步
→ 直到结束
→ 最后统一回收/逐页扫描
→ 人工校对 + 确认真正未分配的题组
→ 保存 Confirmed Trace
→ AI 学情总结
→ 下一轮
```

离线阶段没有实时 AI 判题、没有上传中间答案、没有按需补发新纸。

## 2. AI 如何设计“分流”

0.5 的核心不是固定路由语言，而是**可读、可执行的纸面教学指导**。AI 可以依据正确数、关键错题、知识点表现或组合条件设计补强、进阶、回看、重访或 END。

程序不会因为 targeted condition 排在 score fallback 后面而拒绝，也不要求 0–10 分被机械分区。教师需要检查指导有没有歧义、目标是否存在、重复练习何时停止。

## 3. 学生纸上操作

每到一个题组：

1. 先完成整组 5–10 题；
2. 在记录纸保存首次答案；
3. 整组完成后才打开对应核对页；
4. 对照答案、提示和解析；
5. 按该组 guidance 决定继续哪个组、回看、补强或 END；
6. 重试另填，不能覆盖首次答案。

没有被实际分配到的组保持空白。空白本身不等于错误。

## 4. 四类纸质输出

| 输出 | 作用 |
|---|---|
| 讲解与题册 | 知识讲解、例子、各组问题与演算空间 |
| 提示/核对册 | 提示、答案、解析、每组结束后的 guidance |
| 记录纸 | 首次答案、提示、重试、package/sheet/page 识别信息 |
| 教师指南 | 正确答案、设计理由、来源/模型/审核信息 |

题册与核对册应物理分开或按组遮挡，避免提前看到答案。所有可能使用的组开始前一次发齐。

## 5. Markdown 与分页

AI 文本可使用短 Markdown：标题、粗体、列表、代码和简单表格。公式优先 Unicode/行内代码；当前不宣称完整 LaTeX。程序在屏幕和 PDF 中本地渲染。长内容应分页或明确报错，不能为了塞进页数自动缩小到不可读。

## 6. PDF

- **直接下载 PDF**：本机 Chrome/Edge headless，由服务端生成。
- **打印/保存 PDF**：浏览器打印对话框。
- **Ctrl+P/Cmd+P**：打印按钮异常时的浏览器级备用路径。

若直接 PDF 找不到浏览器、渲染未 ready 或页预算失败，应报错而不是返回伪 PDF。

## 7. 多页记录与扫描

每张 OMR 记录纸最多 8 题；30 题包通常需要 4 页。拍照要求正向、四角定位块和顶部码完整。逐页上传，自动定位失败时可手动四角。0.5 采用内圈填涂面积/色差识别；多选和不确定保持 unknown。

逐页读完后再统一核对，确保已读页面不会被下一页覆盖、同页重扫只更新该页、package/sheet 错配被拒绝、原始识别与人工改动可区分。

## 8. 空白、跳过和自由 guidance

结构化旧包可以由软件重建部分规定路径；**自由 guidance 包不自动重建自然语言路线**。

- 已答题：按实际 first answer 评分；
- 空白题：先标 `unanswered_or_skipped`；
- 教师根据纸面实际路线明确勾选“确认未分配的题组”；
- 被确认跳过的组不能同时存在答案、提示或重试；
- 无法判断的空白继续保持未知。

## 9. 下一轮

确认 trace 后，AI 总结当前主题证据并生成同主题下一轮。下一轮可以是基础、针对性、中档、进阶或再次诊断，不要求机械升难度。任何“掌握/误区”结论都应与具体 evidence refs 绑定。
