## 6. 交付门槛

```text
主题与学生证据
→ AI 生成完整纸包和离线教学指导
→ 教师审核
→ 实际 PDF / 实印纸
→ 学生在没有 AI 的情况下完成至少一条有意义的路线
→ 多页记录纸真实扫描与校对
→ AI 用确认后的证据总结学情
→ 下一轮发生可解释变化
```

同时能够说明为什么需要 AI、为什么采用“自由 guidance + 教师审核”、扫描能读什么/不能读什么、哪些平台是真实调用/哪些只是协议实现、哪些结果是工程证据/学习证据，以及学生本人具体完成了哪些工作。
